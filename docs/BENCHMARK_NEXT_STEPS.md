# Next steps for static Polity evaluation

The project now prioritises useful static Polity practice over a perfect score on the mixed 75-question regression set.

The immediate work is to review a small batch of generated Fundamental Rights and Directive Principles questions. For every item record the key, whether each option note is accurate, whether another option is defensible, whether the cited passage establishes the complete proposition, and whether the question fits its topic and style.

Then build an independent 40–50-question static benchmark across the supported topics. Include direct and statement formats, exceptions and footnotes, and mark expected-withholding cases separately. Freeze it after development; keep answer keys and review sheets out of the corpus and prompts.

The generated-MCQ benchmark must be independently labelled. Its report should include key error, ambiguity, distractor quality, option-note error, grounding failure, topic/style mismatch, acceptance yield, revisions, latency and cost. Model gate results are operational signals, not expert accuracy.

The current Constitution plus selected NCERT corpus is deliberately small. Expand source coverage only when a reviewed question demonstrates a scoped need. Current-affairs and scheme sources are outside the present project objective.

The historical 75-question reports, first-five smoke run and one-question follow-up remain useful failure records. They should not be combined into a new accuracy claim.
